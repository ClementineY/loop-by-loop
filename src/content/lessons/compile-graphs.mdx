## Watch the break

Eager autograd records a fresh route for each call. `torch.compile` asks a different question: can this Python program be captured and reused as optimized FX graphs?

The model does not break. Gradients do not break. **Only compiler capture breaks.**

<NetworkGraphBreakLab client:visible />

## Read the picture

**Eager:** Python chooses one expert; autograd records that route.

**Python `if`:** the compiler stops, Python reads the tensor value, then capture resumes.

**`torch.cond`:** both experts become branch subgraphs inside one compiled graph; only the selected branch runs.

<Callout type="note" title="One useful sentence">
A graph break is a boundary between optimized regions, not a cut in the neural network's mathematics.
</Callout>
