## Read the sign before the formula

- A **negative** gradient says a small increase in `w` will decrease the loss.
- A **positive** gradient says a small increase in `w` will increase the loss.
- A gradient near **zero** says the loss is locally insensitive to `w`.
- A larger absolute value means a stronger local response.

The gradient is local. It describes the curve near the current value; it does not promise that the same slope continues far away.

## Let PyTorch measure it

```python
import torch

w = torch.tensor(0.5, requires_grad=True)
loss = (2 * w - 3) ** 2
loss.backward()

print(loss.item())  # 4.0
print(w.grad)        # tensor(-8.)
```

At `w = 0.5`, the negative gradient means increasing `w` slightly should reduce the loss. The next page shows how PyTorch records the calculation so it can obtain that answer.

<Callout type="tip" title="Sensitivity is not the loss">
The loss is the curve's height. The gradient is its slope at one point. A high loss can have a small gradient, and a low loss can still have a nonzero gradient.
</Callout>
