## What does depth add by itself?

A linear layer scales, mixes, and shifts values. Two such layers still collapse into one:

```text
h = w₁x + b₁
y = w₂h + b₂
  = (w₂w₁)x + (w₂b₁ + b₂)
```

Move every weight and bias below. With no activation the result changes slope and position, but it remains a straight line.

## Where does a network's flexibility come from?

An activation between layers prevents that algebraic collapse. ReLU creates different linear regions on either side of zero. More hidden units create more possible bends; more layers compose those regions into richer shapes.

```python
block = nn.Sequential(
    nn.Linear(1, 8),
    nn.ReLU(),
    nn.Linear(8, 1),
)
```
