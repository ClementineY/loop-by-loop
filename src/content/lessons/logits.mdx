## What does the final linear layer mean?

For classification, each output is a **logit**: an unrestricted score for one class. A logit is not a probability. Its meaning comes from comparison with the other class scores.

<LogitLab client:visible />

## Where should softmax happen?

`CrossEntropyLoss` accepts logits and internally combines a stable log-softmax with negative log likelihood:

```python
logits = model(images)               # [batch, classes]
loss = nn.CrossEntropyLoss()(logits, labels)
predictions = logits.argmax(dim=1)
```

Do not put `Softmax` at the end of the model before this loss. Keeping raw logits avoids duplicated work and numerical instability.

<Callout type="note" title="Binary outputs have two common forms">
Use one logit with `BCEWithLogitsLoss`, or two logits with `CrossEntropyLoss`. Both are valid; the output shape and target encoding must match the chosen loss.
</Callout>
