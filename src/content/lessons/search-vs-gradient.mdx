## Why not perturb the parameters randomly?

Random search is a reasonable baseline: choose a direction, take a small step, and keep it if the loss falls. The problem is not that random directions can never help. The problem is that a neural network may have millions of dimensions, and a random arrow is usually almost perpendicular to the direction that matters.

The lab uses the same step length for every move on `loss = ½‖w‖²`. The histogram shows 120 random moves; the orange line is one move directly opposite the gradient.

## What information does the gradient buy us?

For each parameter, a partial derivative measures one local sensitivity. Put all those sensitivities into one vector and it points in the direction of steepest local increase. Its negative is therefore the steepest local decrease for a sufficiently small step.

```python
optimizer.zero_grad()
loss.backward()       # measure all partial derivatives together
optimizer.step()      # move in the informed direction
```

Random search spends forward passes evaluating guesses. Backpropagation reuses the recorded computation graph to obtain all parameter derivatives in roughly the cost scale of a small number of model evaluations.

<Callout type="note" title="Local, not magical">
The negative gradient is the best infinitesimal direction, not a guarantee for an arbitrarily large jump. Curvature is why the learning rate still matters.
</Callout>
